## Overview

This repository contains the official game database used by FPS Manager.

The database provides compatibility information for:

- NVIDIA DLSS
- AMD FSR
- Intel XeSS

## Purpose

FPS Manager uses this repository to:

- Detect supported games
- Check available upscaling technologies
- Deliver automatic compatibility updates
- Maintain accurate game information
